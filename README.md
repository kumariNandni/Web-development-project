📂 Directory Management System

A modern web-based Directory Management System built using Flask (Python) with a dynamic frontend and database integration.
This project allows users to efficiently manage, search, and analyze directory data with an interactive UI and analytics support.

🚀 Features
📁 Perform full CRUD operations (Create, Read, Update, Delete)
🔍 Real-time search and filtering
📊 Analytics dashboard with charts (Chart.js)
🎨 Modern UI with glassmorphism design
⚡ Smooth frontend interactions using Vanilla JavaScript
🔐 Secure configuration using .env files
🌐 API-based architecture using Flask
🗄️ Supports both SQLite (development) and MySQL (production)
🛠️ Tech Stack
🔹 Frontend
HTML5 – Structure
CSS3 – Styling, layout, animations, glassmorphism UI
JavaScript (Vanilla JS) – DOM manipulation & API integration
Chart.js – Data visualization (analytics pie chart)
FontAwesome – Icons
🔹 Backend
Python – Core programming language
Flask – Web framework for routing & APIs
Flask-SQLAlchemy – ORM for database handling
Flask-CORS – Cross-origin request handling
python-dotenv – Environment variable management
PyMySQL – MySQL database connector
🔹 Database
SQLite – Default local development database
MySQL – Production-ready database (configured via .env)



🧠 System Architecture
Frontend (HTML/CSS/JS) interacts with Flask APIs
Flask Backend processes requests and handles business logic
SQLAlchemy ORM manages database operations
Chart.js visualizes stored data into analytics
📊 Analytics Feature
Integrated Chart.js for visual insights
Displays distribution of directory data
Helps in quick decision-making and data understanding
